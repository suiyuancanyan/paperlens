# 砚读 PaperLens

中外文论文阅读工作台。导入 PDF / Word (.docx)，保存文件、解读与笔记。返回[项目首页](../README.md)。

## Windows 桌面版

在 Windows 上运行 `npm run desktop:pack`，然后打开 `release/win-unpacked/PaperLens.exe`，可为程序创建桌面快捷方式。保留整个 `win-unpacked` 文件夹；包内包含运行环境，使用时无需另外安装 Node.js。文献与笔记保存在「文档\PaperLens资料」，可通过应用菜单「帮助 → 打开资料文件夹」定位。原文件、AI 解读和笔记直接写入资料文件，旧版桌面文献自动迁移；应用设置和运行记录保存在 `%APPDATA%\PaperLens`。

桌面版复用本机 Codex 登录，默认模型仍为 `gpt-6.1-sol`；PDF、Word 和已有笔记可在本机阅读，AI 解读需要连接所选模型服务。网页资料通过完整备份迁入桌面版，迁移后两边各自保存。

重新打包：`npm run desktop:pack`。完整应用输出到 `release/win-unpacked`；分发时需保留整个文件夹。桌面版使用独立的本机服务地址，不占用原网页的地址。

## 启动

安装 Node.js 20.19+ 或 22.12+，进入本目录：

```powershell
npm install
node scripts/copy-pdf-assets.mjs
npm run dev
```

浏览器打开 http://127.0.0.1:4173 。Windows 也可双击 `启动砚读.cmd`。

生产运行：先 `npm run build`，再 `npm start`。默认只监听本机。

## 功能

- 批量拖入 PDF / DOCX，逐页或分段提取原文，自动整理标题候选、摘要、DOI 与图表索引。
- 连接 Chat Completions 兼容模型后，自动整理基本信息、概括、创新点、结果、图表角色、数据集、研究逻辑与适用范围。
- 后台整理队列：原文就绪即可先读，支持进度、取消、失败重试；整理时保持页面打开，中断后重新进入可重试。
- PDF 可选文字层、全文检索、选词翻译与释义、保存高亮；图表裁图、完整页面筛选、逐张大图浏览和手动框选。
- 论文对话支持 Markdown 与公式排版，来源页可点击跳回原文并标记匹配文字。
- 图文摘录带着页码或图像来源进入笔记，阅读页码、标签和缩放自动恢复；标题、作者、年份、期刊及 DOI 可编辑。
- 笔记、解读和收藏按修改字段合并保存，多页面实时同步，提供最近 16 个可恢复修改版本；连续输入的笔记每 30 秒合并一次历史快照。
- 研究画布：按已有解读的节点顺序连接研究路径，支持点击展开、拖动、缩放、键盘导航、同页图表、标记已梳理和一键加入笔记。
- 双图对照：从图表卡片选择两张图，支持跨论文选择、联动或独立缩放、拖动联动移动、展开已有解读及两图加入来源笔记。
- 页面地图：按原文缩略图导航，显示图表页、解读条目分布和笔记位置，支持筛选与一键跳页；Word 显示段落组。
- 专注阅读、收起助手、拖动或用方向键调整助手宽度，以及收藏、已读标记、搜索排序。
- 导出 Markdown、JSON、SVG 逻辑图，以及包含原文件的完整文献库备份；支持恢复备份。
- 响应式中文界面，可选择中文或英文解读。

## 模型连接

默认优先使用这台电脑已登录的 **Codex**，默认模型固定为 **`gpt-6.1-sol`**，推理强度为 `low`。打开「模型与阅读设置」，选择「本机 Codex · 使用现有登录」即可。无需填写 API Key；使用当前 Codex 登录账号的用量。模型输入留空时也使用 `gpt-6.1-sol`。

应用通过官方 `codex exec` 调用本机 Codex，不读取或复制登录凭据。文字通过标准输入传入，图片通过官方 `--image` 附件输入。临时图片在请求结束后清理，临时会话不保留对话文件；阅读任务关闭命令执行、浏览器、应用插件和多代理工具。Codex 会按自身运行机制记录必要的本地运行元数据。

如需重新登录，在 Codex 应用中登录，或在终端运行 `codex login`。找不到命令时，可在 `.env` 设置 `PAPERLENS_CODEX_PATH` 为 Codex 可执行文件的绝对路径，然后重启应用。可用模型和额度由实际登录账号决定。

接口依据：[官方非交互模式说明](https://developers.openai.com/codex/noninteractive)、[登录方式](https://developers.openai.com/codex/auth)。

也可以选择「自定义模型 API」，继续使用下面的兼容接口配置。

在应用的「模型与阅读设置」中填写服务商的基础地址、模型 ID 与 API Key，点击测试连接后保存。请求由本机服务转发，避免浏览器跨域问题。服务地址可填兼容接口的基础路径（如 `https://your-provider.com/v1`），也可填完整 `/chat/completions` 地址。本地模型可使用 `http://127.0.0.1:端口/v1`，无需 Key 时留空。

API Key 只保存在当前页面内存，刷新后需重新输入。地址、模型名与语言偏好保存在本地。也可以将 `.env.example` 复制为 `.env`，在本机服务配置模型。`.env` 已排除在版本控制之外。

## 文件与解读

支持 PDF 与 `.docx`，单篇最大 50 MB。PDF 按页生成缩略图，并根据图注位置生成图表裁图；默认显示图表，可切换完整页面，自动裁图边界可通过框选修正。完整页面保留矢量图、照片、表格和图注；打开大图或读图时，按需加载宽度最高 1600 像素的高清页（高度最高 2200 像素）。Word 提取 PNG/JPEG 等内嵌图片，不支持的 EMF/WMF 或原生图表可先另存为 PDF。旧版 `.doc` 先另存为 `.docx`。Word 按段落组定位，图片保留文档内顺序，不虚构原始页码。

整篇 AI 解读会结合提取文字和最多 6 张实际图片，优先选择图表裁图，再补充识别到图注的页面。每幅图都可单独「看图解读」、输入具体问题、查看与保存原图；图像解读记录随文献保存，并随 Markdown/JSON 和完整备份导出。扫描型 PDF 可直接按页看图；超过 6 页时，整篇解读仅附前 6 页，其他页需逐页解读。文字上限为 18 万字符。自定义 API 需选择支持图片输入的模型。

旧版文献进入「图像与图表」页后，会从已保存的原文件补提取图像，无需重新导入。内置示例展示 [Vaswani 等作者的公开论文](https://arxiv.org/html/1706.03762v7) 中 Figure 1 与 Figure 2 的真实原图，并附来源说明。作者在论文页面中授权附署名的学术用途转载图表；完整论文仍链接至作者公开页面。

网页版文献库使用当前浏览器的 IndexedDB。清理站点数据、更换浏览器或更换访问端口会影响可见文献库。桌面版使用前述资料文件夹；两种环境均可通过使用指南中的「导出备份」备份资料。备份包含原文件、提取文字、解读、笔记、图文摘录、高亮、阅读位置、修改版本与对话，不包含模型 Key。
